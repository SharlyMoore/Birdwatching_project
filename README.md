# BioID — Веб-приложение для определения и каталогизации птиц

Full-stack веб-приложение для бёрдвотчеров и любителей природы: позволяет определять виды птиц по фотографиям, вести личную галерею наблюдений, делиться находками в общей ленте сообщества и проходить интерактивные квизы.

- **Frontend:** React, TypeScript, Vite, Ant Design (`antd`), React Router
- **Backend:** Python 3.13, FastAPI, Pydantic, Uvicorn
- **База данных и ORM:** PostgreSQL, SQLAlchemy, Alembic
- **Контроль версий:** Git


### Лабораторная работа №1 — Интерфейс и каркас Frontend

Определены пользовательские сценарии, реализована вёрстка основных экранов на React + TypeScript с использованием библиотеки компонентов Ant Design и настроена клиентская маршрутизация:
- `AuthPage` (`/auth`) — экран входа, регистрации и гостевого доступа;
- `RecognizePage` (`/recognize`) — загрузка фотографии для определения вида;
- `ResultPage` (`/result`) — отображение результата распознавания и уверенности модели;
- `GalleryPage` (`/gallery`) — личная галерея находок пользователя;
- `CommunityPage` (`/community`) — общая лента публичных наблюдений сообщества;
- `QuizPage` (`/quiz`) — интерактивная викторина по определению видов.


### Лабораторная работа №2 — Backend, REST API и база данных

Реализована серверная часть на FastAPI и спроектирована реляционная схема в PostgreSQL через SQLAlchemy с валидацией запросов/ответов на Pydantic:
- **`users`** (`id`, `username`, `email`, `hashed_password`, `created_at`) — учётные записи пользователей (связь `1:N` с наблюдениями);
- **`bird_species`** (`id`, `common_name`, `latin_name`, `category`, `description`) — справочник видов птиц (связь `1:N` с наблюдениями);
- **`observations`** (`id`, `user_id`, `species_id`, `image_url`, `confidence`, `notes`, `is_public`, `created_at`) — записи наблюдений со внешними ключами на автора и вид птицы.


## Лабораторная работа №3 — Архитектура Frontend и динамический интерфейс

Клиентская часть (`bird-id-frontend`) реорганизована по упрощённой методологии **Feature-Sliced Design (FSD)**:
- `src/app/` — инициализация приложения, провайдеры темы Ant Design, глобальные стили и маршрутизация;
- `src/pages/` — экраны приложения (`AuthPage`, `GalleryPage`, `CommunityPage`, `RecognizePage`, `ResultPage`, `QuizPage`);
- `src/features/` — пользовательские сценарии (`add-observation` — модальная форма добавления наблюдения с клиентской валидацией);
- `src/entities/` — сущности предметной области (`user`, `species`, `observation`): TypeScript-интерфейсы, демонстрационные данные, реактивное хранилище состояния и карточка `ObservationCard`;
- `src/shared/` — общие ресурсы и утилиты.

### Изменения интерфейса в ЛР №3
- Карточки наблюдений вынесены в переиспользуемый компонент `ObservationCard` для устранения дублирования между `GalleryPage` и `CommunityPage`.
- Добавлена модальная форма ручного добавления наблюдений с клиентской валидацией URL, выбора вида и длины заметки.
- Реализованы состояния загрузки (`Spin`), ошибки (`Alert` с кнопкой повтора) и отсутствия данных (`Empty`), а также плавная анимация появления и наведения на карточки.
